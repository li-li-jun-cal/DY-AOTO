1. 环境准备（必读！）
═══════════════════════════════════════════════════════════════════════════

1.1 检查Python版本
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

python --version  # 需要 Python 3.9+


1.2 安装依赖包
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

pip install -r requirements.txt


1.3 安装Playwright浏览器驱动（必须！）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

playwright install chromium

⚠️ 重要提示：
- 这一步是必须的！没有浏览器驱动程序无法运行
- 需要下载约200MB的浏览器文件
- 如果下载慢，可以配置代理或使用国内镜像

1.4 验证安装
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

playwright --version  # 确认playwright已安装

2. 快速开始
═══════════════════════════════════════════════════════════════════════════

2.1 首次运行完整流程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第一步：运行程序
$ python run_douyin.py

第二步：配置登录方式（选择菜单选项 1）
- 推荐选择"二维码扫码登录"
- ⚠️ 重要：选择"关闭无头模式"才能看到二维码

第三步：测试登录（选择菜单选项 2）
- 程序会打开浏览器窗口
- 显示抖音登录页面和二维码
- 使用抖音APP扫描二维码
- 在手机上确认登录
- 等待提示"登录测试成功"

第四步：开始采集数据（选择菜单选项 3-5）
- 登录成功后可以选择任意采集模式
- 建议先用少量数据测试（比如1-2个视频）

2.2 后续运行（已登录过）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果之前成功登录过：
$ python run_douyin.py
# 直接选择采集模式（选项3-5）即可，无需重新登录

3. 登录配置详解
═══════════════════════════════════════════════════════════════════════════

3.1 二维码扫码登录（推荐）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

优点：
✅ 最简单、最安全
✅ 成功率高
✅ 不需要输入任何信息

配置步骤：
1. 选择菜单选项【1】配置登录方式
2. 选择【1】二维码扫码登录
3. 选择【n】关闭无头模式（重要！）
4. 选择菜单选项【2】测试登录
5. 使用抖音APP扫描屏幕上的二维码
6. 在手机上点击"确认登录"
7. 等待提示登录成功

注意事项：
⚠️ 必须关闭无头模式才能看到二维码
⚠️ 二维码有效期约60秒，过期需重新运行
⚠️ 确保手机和电脑在同一网络环境


3.2 手机号验证码登录
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

优点：
✅ 适合企业用户
✅ 可以自动化接收验证码

配置步骤：
1. 选择菜单选项【1】配置登录方式
2. 选择【2】手机号验证码登录
3. 输入手机号
4. 选择菜单选项【2】测试登录
5. 程序会自动填写手机号
6. 点击"获取验证码"
7. 输入收到的验证码
8. 可能需要滑动验证码（程序会自动处理）

注意事项：
⚠️ 可能会触发滑动验证码
⚠️ 需要实际接收短信验证码
⚠️ 验证码有效期通常为5分钟


3.3 Cookie登录（高级）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

优点：
✅ 适合调试和测试
✅ 可以复用已有登录状态

配置步骤：
1. 使用浏览器登录抖音网页版
2. 按F12打开开发者工具
3. 找到Cookie并复制
4. 选择菜单选项【1】配置登录方式
5. 选择【3】Cookie登录
6. 粘贴Cookie

注意事项：
⚠️ Cookie有效期通常较短（1-7天）
⚠️ 需要手动获取和更新Cookie
⚠️ 仅适合高级用户


3.4 无头模式说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

无头模式 = 开启：
- 不显示浏览器窗口
- 适合后台运行、自动化任务
- ❌ 无法看到二维码
- ❌ 无法手动处理验证码

无头模式 = 关闭（推荐首次使用）：
- 显示浏览器窗口
- ✅ 可以看到二维码
- ✅ 可以手动处理验证码
- 适合调试和首次登录

4. 三大功能模式详解
═══════════════════════════════════════════════════════════════════════════

4.1 模式一：关键词搜索
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能说明：
搜索指定关键词的视频，并采集评论数据

使用步骤：
1. 选择菜单选项【3】
2. 输入搜索关键词（例如：美食、玩具）
3. 设置采集视频数量（例如：5）
4. 设置每个视频的评论数量（例如：20）
5. 确认开始采集

示例：
输入关键词：美食
采集视频数：5个
每个视频评论数：20条
总计采集：5个视频，最多100条评论

输出数据：
- data/douyin/csv/videos/美食_videos_YYYYMMDD.csv
- data/douyin/csv/comments/美食_comments_YYYYMMDD.csv


4.2 模式二：指定视频详情
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能说明：
精准采集指定视频的评论数据

支持的格式：
✅ 完整URL: https://www.douyin.com/video/7525538910311632128
✅ 短链接: https://v.douyin.com/drIPtQ_WPWY/
✅ 视频ID: 7525538910311632128

使用步骤：
1. 选择菜单选项【4】
2. 输入视频URL或ID（多个用逗号分隔）
3. 确认开始采集

示例：
输入：https://www.douyin.com/video/7525538910311632128
将采集该视频的所有评论

输出数据：
- data/douyin/csv/comments/detail_comments_YYYYMMDD.csv


4.3 模式三：创作者主页
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能说明：
采集指定创作者发布的所有视频评论

支持的格式：
✅ 完整主页URL: https://www.douyin.com/user/MS4wLjABAAAA...
✅ sec_user_id: MS4wLjABAAAA...

使用步骤：
1. 选择菜单选项【5】
2. 输入创作者URL或ID（多个用逗号分隔）
3. 设置每个创作者的采集视频数量
4. 确认开始采集

示例：
输入：https://www.douyin.com/user/MS4wLjABAAAA...
采集视频数：10个
将采集该创作者最新的10个视频的所有评论

输出数据：
- data/douyin/csv/comments/creator_comments_YYYYMMDD.csv

    │   └── videos/               # 视频数据
    │       └── 关键词_videos_20250116_123456.csv

5.2 CSV文件字段说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

评论CSV字段：
- video_id: 视频ID
- video_title: 视频标题
- video_url: 视频链接
- comment_id: 评论ID
- content: 评论内容
- nickname: 评论者昵称
- create_time: 评论时间
- ip_location: IP归属地
- like_count: 点赞数
- sub_comment_count: 二级评论数

视频CSV字段：
- aweme_id: 视频ID
- title: 标题
- desc: 描述
- create_time: 发布时间
- nickname: 作者昵称
- liked_count: 点赞数
- comment_count: 评论数
- share_count: 分享数

6. 常见问题解决
═══════════════════════════════════════════════════════════════════════════

6.1 环境安装问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: playwright install chromium 失败？
A: 1. 使用管理员权限运行
   2. 配置代理：set HTTPS_PROXY=http://proxy:port
   3. 或手动下载浏览器

Q: ModuleNotFoundError: No module named 'playwright'
A: pip install playwright

Q: 提示缺少依赖包？
A: pip install -r requirements.txt


6.2 登录问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 看不到二维码？
A: ⚠️ 必须关闭无头模式！
   在配置登录方式时选择"n"关闭无头模式

Q: 二维码显示不清楚？
A: 1. 调整终端窗口大小
   2. 直接在浏览器窗口中扫描

Q: 扫码后提示失败？
A: 1. 检查网络连接
   2. 重新运行测试登录
   3. 尝试其他登录方式

Q: 登录后立即退出？
A: 1. 可能需要滑动验证码，关闭无头模式手动处理
   2. 检查登录状态是否保存（SAVE_LOGIN_STATE = True）

Q: 提示 "httpx.ConnectError: All connection attempts failed"？
A: 这是网络连接错误，可能的原因和解决方法：
   1. 代理配置错误：
      - 检查 config/base_config.py 中的 ENABLE_IP_PROXY 设置
      - 如果设置为 True，请改为 False 重试
   2. 网络连接问题：
      - 检查网络是否正常，能否访问抖音网站
      - 尝试关闭VPN或代理软件
   3. 防火墙拦截：
      - 检查防火墙设置，允许Python访问网络
   4. 重要提示：
      - 测试登录功能已优化，不会触发数据采集API调用
      - 如果仍遇到连接错误，请检查上述配置


6.3 采集问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 采集的评论数量不足？
A: 1. 检查视频本身的评论数
   2. 增加评论数量设置
   3. 检查是否触发了反爬虫限制

Q: 程序运行缓慢？
A: 1. 适当增加 CRAWLER_MAX_SLEEP_SEC 避免封禁
   2. 减少并发数
   3. 考虑使用代理IP

Q: 提示账号被风控？
A: 1. 停止采集，等待一段时间
   2. 更换账号或IP
   3. 减少采集频率


6.4 浏览器问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 浏览器无法启动？
A: 1. 确认已运行 playwright install chromium
   2. 检查防火墙设置
   3. 尝试重新安装playwright

Q: 浏览器窗口一闪而过？
A: 1. 关闭无头模式
   2. 查看错误日志
   3. 检查是否有异常退出
