3. 三大功能模式详解
═══════════════════════════════════════════════════════════════════════════

3.1 模式一：关键词搜索 (search)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 功能说明:
   搜索指定关键词的视频，并采集评论数据

📝 配置步骤:

   1. 修改 config/base_config.py:
      CRAWLER_TYPE = "search"
      KEYWORDS = "玩具,美食"  # 多个关键词用逗号分隔
      CRAWLER_MAX_NOTES_COUNT = 5  # 采集5个视频
      CRAWLER_MAX_COMMENTS_COUNT_SINGLENOTES = 20  # 每个视频20条评论

   2. 修改 config/dy_config.py:
      SEARCH_SORT_TYPE = 1  # 0=综合 1=最多点赞 2=最新发布

   3. 运行:
      python main.py --type search --keywords "玩具"

💡 使用场景:
   - 市场调研：了解某个产品的用户评价
   - 热点分析：追踪热门话题的讨论
   - 竞品分析：查看竞争对手的内容


3.2 模式二：指定视频详情 (detail)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 功能说明:
   精准采集指定视频的评论数据

📝 配置步骤:

   1. 修改 config/dy_config.py:
      DY_SPECIFIED_ID_LIST = [
          "https://www.douyin.com/video/7525538910311632128",
          "https://v.douyin.com/drIPtQ_WPWY/",
          "7202432992642387233"
      ]

   2. 修改 config/base_config.py:
      CRAWLER_TYPE = "detail"

   3. 运行:
      python main.py --type detail

💡 支持的格式:
   ✅ 完整URL: https://www.douyin.com/video/7525538910311632128
   ✅ 短链接: https://v.douyin.com/drIPtQ_WPWY/
   ✅ 视频ID: 7525538910311632128
   ✅ 搜索页带modal_id的URL

💡 使用场景:
   - 爆款分析：深度分析某个爆款视频的评论
   - 用户反馈：收集特定视频的用户反馈
   - 内容优化：了解观众对某个内容的看法


3.3 模式三：创作者主页 (creator)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 功能说明:
   采集指定创作者发布的所有视频评论

📝 配置步骤:

   1. 修改 config/dy_config.py:
      DY_CREATOR_ID_LIST = [
          "https://www.douyin.com/user/MS4wLjABAAAA...",
          "MS4wLjABAAAATJPY7LAlaa5X-c8uNdWkvz0jUGgpw4eeXIwu_8BhvqE"
      ]

   2. 修改 config/base_config.py:
      CRAWLER_TYPE = "creator"
      CRAWLER_MAX_NOTES_COUNT = 10  # 每个创作者采集10个视频

   3. 运行:
      python main.py --type creator

💡 支持的格式:
   ✅ 完整主页URL: https://www.douyin.com/user/MS4wLjABAAAA...
   ✅ sec_user_id: MS4wLjABAAAA...

💡 使用场景:
   - 博主追踪：持续追踪某个博主的内容表现
   - 竞品分析：分析竞争对手博主的粉丝反馈
   - KOL评估：评估KOL的粉丝互动质量

4. 命令行参数使用
═══════════════════════════════════════════════════════════════════════════

4.1 基础参数
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

--lt [qrcode|phone|cookie]        # 登录方式
--save_data_option [csv|json|db|sqlite]  # 数据保存格式


4.2 评论参数
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

--get_comment [true|false]        # 是否采集一级评论
--get_sub_comment [true|false]    # 是否采集二级评论


4.3 使用示例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

python main.py --type search --keywords "美食" --save_data_option csv

# 示例2: 采集指定视频并保存为JSON
python main.py --type detail --save_data_option json

# 示例3: 采集创作者视频并包含二级评论
python main.py --type creator --get_sub_comment true

5. 配置文件说明

5.1 基础配置 (config/base_config.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PLATFORM = "dy"                    # 平台固定为抖音
KEYWORDS = "玩具"                   # 搜索关键词
LOGIN_TYPE = "qrcode"              # 登录方式
CRAWLER_TYPE = "search"            # 爬取类型
HEADLESS = True                    # 无头模式（不显示浏览器）
SAVE_LOGIN_STATE = True            # 保存登录状态
SAVE_DATA_OPTION = "csv"           # 数据保存格式

# 爬取控制
START_PAGE = 1                     # 起始页码
CRAWLER_MAX_NOTES_COUNT = 2        # 最大视频数
MAX_CONCURRENCY_NUM = 1            # 并发数
ENABLE_GET_COMMENTS = True         # 是否采集评论
CRAWLER_MAX_COMMENTS_COUNT_SINGLENOTES = 20  # 单视频最大评论数
ENABLE_GET_SUB_COMMENTS = False    # 是否采集二级评论

# 高级选项
ENABLE_IP_PROXY = False            # 是否使用代理
ENABLE_CDP_MODE = False            # 是否使用CDP模式


5.2 抖音专属配置 (config/dy_config.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SEARCH_SORT_TYPE = 1               # 搜索排序: 0=综合 1=点赞 2=最新
DY_SPECIFIED_ID_LIST = [...]       # 指定视频列表
DY_CREATOR_ID_LIST = [...]         # 指定创作者列表

6.2 CSV文件字段说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

评论CSV (comments):
- video_id: 视频ID
- video_title: 视频标题
- video_url: 视频链接
- comment_id: 评论ID
- content: 评论内容
- nickname: 评论者昵称
- create_time: 评论时间
- ip_location: IP归属地
- like_count: 点赞数
- sub_comment_count: 二级评论数

视频CSV (videos):
- aweme_id: 视频ID
- aweme_type: 视频类型
- title: 标题
- desc: 描述
- create_time: 发布时间
- user_id: 用户ID
- nickname: 昵称
- liked_count: 点赞数
- comment_count: 评论数
- share_count: 分享数
- video_url: 视频链接

7. 常见问题解决
═══════════════════════════════════════════════════════════════════════════

7.1 登录问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 二维码登录失败？
A: 1. 确保手机抖音已登录
   2. 扫码后在手机上确认登录
   3. 检查网络连接是否正常
   4. 尝试关闭无头模式: HEADLESS = False

Q: 登录后立即退出？
A: 1. 检查是否有滑块验证，关闭无头模式手动处理
   2. 使用 SAVE_LOGIN_STATE = True 保存登录状态


7.2 采集问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 采集的评论数量不足？
A: 1. 检查视频本身的评论数
   2. 增加 CRAWLER_MAX_COMMENTS_COUNT_SINGLENOTES
   3. 检查是否触发了反爬虫限制

Q: 程序运行缓慢？
A: 1. 适当增加 CRAWLER_MAX_SLEEP_SEC 避免封禁
   2. 减少并发数: MAX_CONCURRENCY_NUM = 1
   3. 考虑使用代理IP

Q: 无法获取视频数据？
A: 1. 检查视频ID/URL是否正确
   2. 确认视频未被删除或设为私密
   3. 查看终端的错误提示


7.3 输出问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 找不到输出文件？
A: 1. 检查 data/douyin/ 目录
   2. 确认 SAVE_DATA_OPTION 配置正确
   3. 查看程序是否报错

Q: CSV文件乱码？
A: 使用 Excel 打开时选择 UTF-8 编码
   或使用专业的CSV编辑器如 VS Code


7.4 环境问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: playwright 安装失败？
A: 1. 使用管理员权限运行
   2. 手动安装: python -m playwright install chromium
   3. 检查网络代理设置

Q: 依赖包安装失败？
A: 1. 升级 pip: pip install --upgrade pip
   2. 使用国内镜像: pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
