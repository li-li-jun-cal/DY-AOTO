===============================================================
抖音自动回复评论工具 - 使用说明
===============================================================

⚠️ 重要警告
===============================================================
1. 自动评论可能违反抖音服务条款
2. 可能导致账号被限制、降权或封禁
3. 建议使用小号进行测试
4. 严格控制回复频率和数量
5. 回复内容要自然，避免垃圾广告

本工具仅供学习研究，使用者需自行承担风险！

===============================================================
功能说明
===============================================================

本工具可以：
✅ 读取采集到的评论数据（CSV格式）
✅ 根据关键词筛选评论
✅ 自动在抖音视频下回复评论
✅ 支持多个回复模板随机选择
✅ 自动控制回复间隔（30-60秒）
✅ 模拟人工输入（逐字输入）

===============================================================
使用步骤
===============================================================

步骤1: 先采集评论数据
--------------------------------------------------------------
使用主程序采集评论：

python run_douyin.py

选择【5】创作者主页模式（推荐）
或选择【4】指定视频详情模式

采集后会在 data/douyin/csv/ 目录生成评论文件：
- XXX_comments_YYYYMMDD_hhmmss.csv


步骤2: 运行自动回复工具
--------------------------------------------------------------
python auto_reply_comments.py

按照提示操作：

1️⃣ 确认警告提示（输入 yes）

2️⃣ 选择评论数据文件
   - 程序会列出可用的CSV文件
   - 选择要处理的文件

3️⃣ 筛选评论（可选）
   - 可以根据关键词筛选
   - 例如：好用,推荐,喜欢
   - 也可以不筛选，处理所有评论

4️⃣ 设置回复内容
   - 输入回复模板（每行一个）
   - 例如：
     正巧我也有
     我家也有哦
     同款！
     好巧，我也在用
   - 程序会随机选择模板回复

5️⃣ 设置回复数量
   - 建议每次不超过10-20条
   - 避免被检测为垃圾评论

6️⃣ 确认并开始
   - 检查信息无误后输入 yes 开始
   - 程序会自动回复，可随时 Ctrl+C 中断


步骤3: 监控执行过程
--------------------------------------------------------------
程序会在浏览器中自动执行：
1. 访问视频页面
2. 定位评论
3. 输入回复内容
4. 发送回复
5. 等待30-60秒后继续下一条

你可以在浏览器中观察整个过程。

===============================================================
安全建议
===============================================================

1. 频率控制
--------------------------------------------------------------
✅ 每条回复间隔30-60秒（已内置）
✅ 每次回复不超过10-20条
✅ 每天总回复不超过50条
❌ 不要连续运行多次

2. 内容建议
--------------------------------------------------------------
✅ 回复内容要自然、真实
✅ 使用多个不同的回复模板
✅ 避免完全相同的内容
❌ 不要包含广告、链接
❌ 不要使用敏感词汇

3. 账号安全
--------------------------------------------------------------
✅ 建议使用小号测试
✅ 新账号先养号（正常使用1-2周）
✅ 定期手动使用抖音
❌ 不要在主号上大量使用

4. 风险规避
--------------------------------------------------------------
✅ 遇到验证码立即停止
✅ 如果回复失败，检查账号状态
✅ 发现异常立即停止使用
❌ 不要强行突破限制

===============================================================
常见问题
===============================================================

Q1: 找不到评论输入框？
--------------------------------------------------------------
A: 这是正常的，因为抖音的页面结构可能变化。

   解决方法：
   1. 手动在浏览器中打开视频
   2. 检查评论区的HTML结构
   3. 修改 auto_reply_comments.py 中的选择器

   关键代码位置：
   input_selector = 'textarea[placeholder*="评论"]'
   send_button = 'button:has-text("发布")'


Q2: 回复发送失败？
--------------------------------------------------------------
A: 可能原因：
   1. 账号被限制评论（需要验证或冷却）
   2. 评论内容包含敏感词
   3. 回复过于频繁

   解决方法：
   1. 等待1小时后重试
   2. 更换回复内容
   3. 降低回复频率


Q3: 账号被限制怎么办？
--------------------------------------------------------------
A: 如果收到限制提示：
   1. 立即停止使用工具
   2. 正常手动使用抖音1-2周
   3. 不要在该账号上继续使用自动工具

   预防措施：
   - 使用小号测试
   - 严格控制频率
   - 定期手动使用


Q4: 如何提高成功率？
--------------------------------------------------------------
A:
   1. 新账号先养号（正常使用1-2周）
   2. 每天手动发布1-2条内容
   3. 回复内容要自然、多样化
   4. 严格控制频率（每天<50条）
   5. 避开高峰时段（晚上8-11点）
   6. 回复与视频相关的内容

===============================================================
修改选择器（高级）
===============================================================

如果程序无法找到评论输入框，需要修改选择器。

打开 auto_reply_comments.py，找到这些行：

# 评论输入框选择器（约第68行）
input_selector = 'textarea[placeholder*="评论"], textarea[data-e2e="comment-input"]'

# 发送按钮选择器（约第88行）
send_button = '[data-e2e="comment-post"], button:has-text("发布")'

如何找到正确的选择器：
1. 在浏览器中打开抖音视频
2. 按F12打开开发者工具
3. 点击左上角的选择元素工具
4. 点击评论输入框
5. 在Elements标签中查看HTML结构
6. 找到合适的选择器（class、data-*属性等）
7. 修改代码中的选择器

===============================================================
数据格式
===============================================================

CSV文件应包含以下字段：
- video_url 或 视频链接: 视频URL
- comment_id 或 评论ID: 评论ID（可选）
- content 或 评论内容: 评论内容

示例：
video_url,comment_id,content,nickname
https://www.douyin.com/video/123,abc123,这个好用,用户A
https://www.douyin.com/video/456,def456,推荐,用户B
