===============================================================
解决搜索返回空结果问题 - 人机验证
===============================================================

问题确认：
✅ 登录成功（Cookie数量: 55, 包含sessionid: True）
❌ 搜索返回空（'search_nil_type': 'verify_check'）
✅ 主页采集正常工作

原因：
抖音检测到自动化行为，要求人机验证（滑块/验证码）。
搜索功能比主页访问有更严格的反爬虫检测。

===============================================================
方案1: 手动在浏览器中完成验证（推荐）
===============================================================

步骤：
1. 保持程序运行（不要关闭浏览器）
2. 手动在浏览器中访问 https://www.douyin.com
3. 在搜索框输入关键词（如"玩具"）并搜索
4. 完成滑块验证或其他人机验证
5. 验证通过后，浏览器Cookie会更新
6. 重新运行搜索采集

注意：
- 验证后的Cookie有效期通常为几小时
- 过一段时间可能需要重新验证

===============================================================
方案2: 使用创作者主页模式代替搜索（推荐）
===============================================================

由于主页采集没问题，可以用这个方式：

1. 先手动在浏览器中搜索关键词
2. 找到感兴趣的创作者主页
3. 复制创作者主页URL
4. 使用【5】创作者主页模式采集

示例：
python run_douyin.py
选择【5】创作者主页模式
输入创作者URL: https://www.douyin.com/user/MS4wLjABAAAA...
设置采集数量: 10个视频

优点：
- 不触发搜索验证
- 可以采集特定创作者的所有视频
- 更稳定

===============================================================
方案3: 降低请求频率（辅助方案）
===============================================================

修改配置以降低被检测的概率：

打开 config/base_config.py，修改：

CRAWLER_MAX_SLEEP_SEC = 5    # 从2秒改为5秒，增加延迟
MAX_CONCURRENCY_NUM = 1      # 确保并发数为1

这样会：
- 请求之间有更长延迟
- 更像人工操作
- 但仍可能触发验证

===============================================================
方案4: 关闭无头模式，手动辅助（临时方案）
===============================================================

1. 确保 config/base_config.py 中 HEADLESS = False
2. 运行搜索采集
3. 当看到验证提示时，手动在浏览器中完成验证
4. 验证通过后程序会继续执行

===============================================================
为什么主页采集没问题，搜索有问题？
===============================================================

抖音的反爬虫策略：
1. 搜索功能 - 高风险操作，严格检测
   - 容易被批量爬取
   - 触发验证码

2. 主页访问 - 低风险操作，宽松检测
   - 正常用户行为
   - 较少触发验证

3. 详情页访问 - 中等风险
   - 直接访问视频ID
   - 偶尔触发验证

===============================================================
推荐使用顺序
===============================================================

优先级1: 使用创作者主页模式
- 最稳定
- 不触发验证
- 可以采集特定创作者的内容

优先级2: 手动完成验证后使用搜索
- 在浏览器中手动搜索并完成验证
- 验证通过后重新运行采集
- 有效期几小时

优先级3: 增加延迟降低检测
- 设置更长的CRAWLER_MAX_SLEEP_SEC
- 减少采集数量
- 分批次采集

===============================================================
最佳实践
===============================================================

1. 使用组合策略：
   - 手动在浏览器搜索关键词
   - 找到相关创作者
   - 使用创作者模式批量采集

2. 避免高频搜索：
   - 不要短时间内多次搜索
   - 每次搜索间隔至少5-10分钟
   - 采集数量不要太大（建议≤20）

3. 保持登录状态：
   - 定期（每天）使用浏览器手动访问抖音
   - 保持Cookie活跃
   - 避免长时间不活动
